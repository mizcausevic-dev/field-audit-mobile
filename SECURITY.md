# Security policy

## Supported versions

Only the latest tagged release is supported for security fixes.

## Reporting a vulnerability

Please open a private security advisory or contact through `kineticgain.com/contact`.

## Scope notes

- All data in this repo is synthetic demonstration data.
- This repo does not process live field audits, permits, or safety submissions.
- Production mobile inspection systems require formal review for offline storage, device management, supervisor access control, evidence retention, and deployment hardening before operational use.
